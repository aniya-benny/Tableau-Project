Amazon Sales Analysis Dashboard – Tableau

This project is an interactive Amazon Sales Analysis Dashboard developed using Tableau to analyze sales performance and extract business insights from Amazon sales data. The dashboard provides a comprehensive view of sales trends, product performance, customer purchasing patterns, and operational metrics.

Key Features
Sales overview with KPIs:
Total Revenue
Total Quantity Sold
Total Products
Product Categories
Weekly sales trend analysis
Quantity analysis by:
Category
Sales channel
Courier status
Product size
State-wise sales visualization using map analysis
Top-performing states based on sales quantity
Order status tracking (Shipped, Cancelled, Pending, Returned)
B2B sales insights
Tools & Technologies
Tableau – Data visualization and dashboard development
Excel/CSV Dataset – Data source and preprocessing
Insights Generated
Identified top-performing product categories and states
Tracked weekly sales patterns and revenue trends
Evaluated shipping performance and delivery status
Compared sales channels and customer buying behavior

This dashboard helps transform raw sales data into meaningful insights, supporting data-driven business decisions and performance monitoring.# Tableau-Project
